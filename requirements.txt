# Deps of the Krea 2 app itself. bootstrap.py installs this file together
# with ComfyUI's requirements.txt in a single pip resolver pass, so a plain
# `python app.py` on a bare pod also ends up satisfying it.
# torch is intentionally NOT listed — it comes from the RunPod PyTorch base
# image (and ComfyUI's own requirements).
# The web app. FastAPI serves the API and the embedded React bundle;
# uvicorn runs it. Deliberately NOT uvicorn[standard]: the extras are
# uvloop and httptools, both compiled, and neither buys anything at one
# customer per process — while both would have to be taught to Nuitka.
fastapi>=0.115
uvicorn>=0.30
# Multipart form parsing, which FastAPI needs to accept an upload and
# does not vendor. Every image that reaches /api/v1/uploads arrives
# through it, so it is a hard dependency of the Inpaint and Edit tabs
# rather than an optional extra.
python-multipart
websocket-client>=1.6
requests
huggingface_hub
# Xet transfer for the Hub. Not optional in practice: without it every
# download of a Xet-backed repo falls back to single-stream HTTP, which
# turns a model fetch that takes seconds into one that takes many minutes.
# It has to be compiled into the binary too — see --include-package in
# build.sh — because the bundled huggingface_hub resolves imports inside
# the Nuitka bundle and cannot see a pip-installed copy on the pod.
hf_xet
safetensors
# Mask compositing and input downscaling in handlers.py, and the gallery
# thumbnails in gallery_index.py. Listed explicitly because the app imports
# it unconditionally at startup: it happens to arrive with ComfyUI's own
# requirements today, which makes a hard dependency look like a transitive
# one right up until a ComfyUI release drops it.
Pillow>=10
